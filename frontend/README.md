# Smart QPG Frontend (Modular)

This is a redesigned modular frontend for Smart QPG.

## Structure
- `css/` - Design system with tokens, base styles, components, and page-specific styles
- `js/` - Modular JavaScript with API clients, components, core utilities, and pages
- `assets/` - Icons, images, and other static assets

## Features
- Clean, modern academic SaaS design
- Light and dark themes with system preference detection
- Fully responsive design
- Modular architecture for maintainability
- Preserves all existing backend integrations
